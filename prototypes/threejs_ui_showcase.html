普通大模型编写 3D UI 典型致命硬伤：
  • 缺少 Billboard 摄像机对齐 (No Facing)：UI 仅仅作为一个固定的 3D 平面贴在敌人头顶。视角转到侧面时，血条直接变成了一条看不见的薄线！
  • 被场景墙体深度切断 (Depth Clipping)：未禁用 depthTest 或未设置分层渲染通道，敌人走到障碍物后方时，头顶 UI 被墙壁粗暴切成两半。
  • 屏幕外镜像倒飞 (Behind Camera Inversion)：敌人走到摄像机后方时，直接除以负的 $W$ 分量导致未做剔除，UI 镜像颠倒倒飞到屏幕正中央。

按住鼠标左键可拖拽旋转 3D 视角
搭载技能工业级 3D 空间 UI 规范：
  • 四元数法线绝对对齐 (Spherical Billboard)：每一帧实时同步 quaternion.copy(camera.quaternion)，无论摄像机如何俯仰旋转，血条永远正对屏幕。
  • 深度穿模覆盖 (Depth Buffer Override)：设置 depthTest=false 与独立渲染层级，敌人虽被墙遮挡，但 HUD 高对比穿透半透提示。
  • 视网膜边缘雷达钳位 (Off-screen Viewport Clamping)：敌人移出视野或移到摄像机背后时，自动进行视口边缘裁切并贴边显示呼吸警示三角标与精准米数！
3D 摄像机投影状态： Yaw: 30° | Pitch: 25° | 敌人坐标: (2.2, 1.0, -1.8)
